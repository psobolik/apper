# apper

Oct 2025; Updated May 2026

Copyright (c) Paul Sobolik

License: [MIT](LICENSE)

A simple TUI program for launching GUI apps from a Linux terminal. This is exactly like running the GUI app from the command line, so
the spawned app may write junk to the terminal. You can get your shell prompt back by hitting the `Enter` key.

This program uses desktop files defined by [Freedesktop.org](https://www.freedesktop.org/wiki/Specifications/desktop-entry-spec/).
